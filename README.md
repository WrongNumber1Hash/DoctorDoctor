# About this Game

**What is the game about?**
The role of the emergency room doctor is to make decisions for treatment of patients that come into the Emergency Room. Each different role has the goal of collaborating to achieve both the hospital goals and their individual goal. 

**Player Roles**
1. Patient
2. Nurse
3. Doctor
4. Admin

**Non-player Character Roles**
1. Student Intern - Doctor
2. Student Nurse
3. Patient (for patients other than character roles)
4. Admin (if no character role)

**Player Goals**
## Admin
Goal is to get all patients triaged and sorted in 3 shifts or 24 rounds of the game. Finish the game with more money than you started with for the hospital.

## Doctor
Goal is to have highest number of patients successfully treated.

## Nurse
Goal is to have patients spend less time in reception and triage.

## Patient
Goal is to have treatment for pain and illness at lowest cost.

**Strategy**
Each person will have a different strategy to achieve the goal.
